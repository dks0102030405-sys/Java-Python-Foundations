# Java & Python Foundations

Welcome to my Computer Science repository! This collection documents my progression from foundational programming logic in Java (ICSE background) to algorithmic problem-solving and computational chemistry tools in Python during Class 11.

## 📁 Repository Contents

### 🧪 Science & Chemistry Computational Tools
- **`oxidation_no.java`**: Calculates the average oxidation state of a central atom using net charge, oxygen, and hydrogen counts with floating-point precision.
- **`inorganic_trends.py`**: Analyzes Period 2 and Period 3 atomic numbers to identify half-filled ($p^3$) stability and pairing penalty ($p^4$) electronic configurations.
- **`PeriodicTable.java`**: Interactive periodic table lookup tool built in Java.

### ☕ Java Algorithms & Data Structures
- **`Peak.java`**: Identifies local peak elements in a 1D array using boundary-safe linear traversal.
- **`GPA.java`**: Sorts subject scores in descending order using Bubble Sort and computes percentage-based academic distinctions.
- **`matrix_diagonal_sum.java`**: Computes the primary diagonal sum of a 2D matrix to practice multi-dimensional array indexing.
- **`Fibonacci.java`**: Generates the Fibonacci sequence up to a user-defined limit using iterative loop optimization.

### 🐍 Python Fundamentals
- **`Athletes_score.py`**: Evaluates multi-match athletic performance metrics using conditional grading thresholds.
- **`string_reversal.py`**: Performs manual index-based string reversal without built-in slicing shortcuts.

## 🛠️ Tech Stack
- **Languages:** Java, Python 3
- **Core Concepts:** Arrays & 2D Matrices, Sorting Algorithms, Control Flow, Scientific Computation
